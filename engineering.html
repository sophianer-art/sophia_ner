Python Projects - August 2026

Virtual String

Tools: Python, NumPy, Matplotlib

A Python simulation of a vibrating cello string using wave equations and harmonic frequencies.

Learning Python is a skill I’ve wanted to develop for a while, as it is an important tool for working with large sets of data. I have some experience with programming from taking APSC 160 (Introduction to Computation in Engineering Design - Coding in C) at UBC, but as a Materials Engineering student, there are not many opportunities to use this language. For learning Python, I used YouTube to learn the basics of Python (this playlist specifically!), and Google to find sources for libraries that I needed to do specific functions for this project and ChatGPT to help with debugging.

Combining my interests in music with programming, and using some basic knowledge about simple harmonic motion from PHYS 157, I decided to model a simplistic cello string.

Since this was my first project coding with Python, I decided to break down this project into subprojects.

String Animation

I started with the string animation since I was familiar with generating plots from watching the YouTube videos. For modelling the cello string itself, I used the length (0.69 m) and frequency (220Hz) of a standard cello A string, and estimated the amplitude of the wave to be 5mm (the amplitude is related to how ‘strongly’ you play the string, so this is variable). To create the string equation, I used the standing wave equation.

$$ y = A \sin\Big(\frac{n\pi x}{L}\Big) \cos(2\pi n f t) $$ $$ \begin{aligned} A &= \text{amplitude} \\ n &= \text{harmonic number} \\ x &= \text{position along string} \\ L &= \text{length of string} \\ f &= \text{frequency} \\ t &= \text{time} \end{aligned} $$

I made a separate equation for each harmonic, and added them together using the principal of superposition. The final waveform that I used has eight harmonics.

Using the FuncAnimation from matplotlib to create the animation of the wave.

String Audio

To make the audio, I used the same cello string properties that I used for the animation, and the same equations that I used to make the wave. I added an amplitude envelop so that there was an attack and delay to the audio.

The Python module sound device was imported to play the audio, and the SciPy library was used to save the audio as a WAV file.

String Animation + Audio

After getting the animation and audio to work independently, I wanted to have the animation and audio play together in one file. I used the same code from the animation and audio and animation subprojects. With the MoviePy library, combined the animation and audio into one file, which is what you see above.

The next thing I want to do with this project is add material properties from different brands of strings. Eventually, I would like to prompt the use to select a brand of string and then the program would output the audio for each string.

However, since most strings are either composites or made out of a ‘synthetic’ material not disclosed by the string company, gathering the material properties has added a layer of complexity for creating this simulation.

EUS Engineering Design Competition - March 2026

Tools:Design, Prototyping, Presentation

The Engineering Undergraduate Society (EUS) hosts multiple design competitions every year. My classmates and I entered the Junior category where we were tasked to design and build a mechanism to launch mini beanbags at a specified target. We were given four hours to design, build, and troubleshoot, along with a set amount of building materials and a $20 budget to use at the “shop”. Teams were marked on presentation of our beanbag-launching device and being able to accurately land in a bullseye five meters away.

My team build a catapult, where we experimented with the shape basket to hold the beanbag, the strength of different strings, and launch angle of the arm. Our team ended up scoring the maximum amount of points for accuracy and we came in first for our presentation. We won the Junior category of the design competition along with $150.

Arduino Projects - August 2025

Tools: Arduino, C++, Tinkercad

Electronic musical instruments designed using TinkerCAD and code in C++.

Potentiometer Chromatic Tone Generator

In the code, there is a function that maps the analog input from the potentiometer to a pitch in the range of 120–1500 Hz. When the potentiometer is at position 0, no sound plays.

Keypad Keyboard

To store the pitches in the keypad, I used a 4x4 array to match the setup of the physical keypad. There are two functions that make this simulation work.

The first function checks if a key on the keypad is currently being pressed, and stores the corresponding character into a variable. If a key is pressed, it returns the character associated with the key based on the array. If no key is pressed, it returns a null character.

The second function takes the key that was stored in the variable from the first function and returns the frequency associated with the key. I chose to make the keypad return a C Major scale.

Tennis Ball Trebuchet

Skills Hand and Power Tools, Prototyping, Testing

In my high school engineering class, we were tasked to build a tennis ball launcher. The requirement for this project was to launch a tennis ball a minimum of 10 meters, and we were also graded on precision, having to launch the tennis ball two times and earning extra points if we minimized the distance between the two launches.

With these constraints in mind, my group decided to build a mini trebuchet. The frame of the trebuchet is made of scrap wood found at our high school, and we used a 5 pound counterweight generously loaded to us from the weight room. My groupmate made the sling for the tennis ball from fabric.

Through this project, my group learned how to use many woodworking machines, such as the chop saw, band saw, table saw, and drill press.
